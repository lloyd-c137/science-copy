# 开题手记当前应用逻辑

本文对应开题手记 v1.0 和 Research Coach 1.3.15。面向师生的阅读入口是[系统架构简介](开题手记-系统架构简介.md)。

## 接入和会话

网页入口先查当前浏览器及教学账号是否已连接。未连接时依次安装插件、连接账号、选择文件夹。安装包从当前站按系统下载，安装时可改站点地址。安装窗口生成一次性三位码，最长有效 24 小时。网页确认的账号和安装程序写入的本机凭据一致后才算连好。安装包实际版本由 `/api/plugin-downloads` 从各自清单读取。

`plugin_site.py` 校验账号、角色、课题、阶段轮次、目录归属及提交版本。插件模式下，本机目录选择和打开 Codex 在学生或老师的电脑上完成。已经验证过的目录可在下一阶段复用。同一阶段与轮次可重开已绑定的聊天，新阶段或新版送审用新的聊天范围。原目录被占用时，选择独立文件夹。已绑定路径需要变更或恢复时，从 Codex 入口的故障折叠项处理。

预填消息依次为完整 Skill 调用、`开题手记会话：…`、面向用户的任务句。学生使用 `$research-coach:research-proposal-coach`，老师使用 `$research-coach:research-proposal-review`。项目和阶段由会话绑定解析。首次读项目带网页生成的 `stage_session` 和实际工作目录 `workspace`，后续继续用同一会话。学生按教学简报中的活动和焦点推进，网页阶段控制完成门槛。已读契约和同版本上下文复用，主动复查时带 `known_hash`，缺少影响本轮判断的资料再定向读取。

## 辅导和审核责任

| 阶段 | 网页核对与实际约束 |
| --- | --- |
| A 兴趣探索与问题积累 | 短暂澄清后给 2–3 个不同角度，可都不选。试聊后在收窄和收束处确认方向。已定方向保存观察、主问题、已选子问题、方案、第一步验证和学生理由；其他候选保留在探索记录。 |
| B 形成核心困惑 | 将相关问题归组，留存选择理由、竞争解释及学生确认的关联。 |
| C 搜索诊断与假设发展 | 保存实际搜索、至少两篇独立来源的已读原文比较、研究问题及解释、预测或适用的非实验方案。实测、文献、学生自述、AI 示例及推断各有出处和限制。 |
| D 研究框架与关键验证 | 保存方法、学习价值、实际价值、研究价值、预算与关键验证。核对方法怎样回答问题、如何区分解释及结论边界。计划、演练和实测分别记录。 |
| E 开题计划与答辩准备 | 七章形成固定稿，学生实际答辩引用原话，并绑定稿件 ID 和修订。换稿后核对该稿和自己的答辩。 |
| F 老师审阅与开题决定 | 学生核对在 E 确认的固定稿与对应答辩，由本人送审。老师可暂存草稿，网页发布时才产生正式决定。补证只重开受影响阶段，保留旧稿、答辩及历史决定。 |

普通答疑和追问规则为零项目 MCP 调用。新的具体观察、学生的实质取舍或可继承的草稿在当轮保存增量。有新依据时记录实际读到的范围。绑定失败时，第一次出现值得保存的内容就明确说明尚未写回，并给简短接续要点。详细边界见[学生 Skill](../skills/research-proposal-coach/SKILL.md)及[老师 Skill](../skills/research-proposal-review/SKILL.md)。

学生教练用 `proposal_save_handoff` 保存交接草稿。成功且 `handoff.prepared=true` 才交回整阶段核对。单项需要本人决定时，可单独交接。网页 `research-review` 复用依赖、来源、版本与阶段校验，拒绝模型代确认。单项「保存修改」留在原阶段，最后「确认并继续」才推进。F 预览分开显示计划正文和同稿答辩。老师辅助审阅复用已读取的固定稿和版本，只补读缺项并保存草稿。正式提交换版后从网页开启新审阅。手工审阅可在网页直接完成。

## 数据、同步及维护边界

- Python 服务与 SQLite 保存项目进度、结构化成果、原文档案、固定稿和审阅结果。应用通过提案和版本校验保留学生选择，过期或超出归属的写入会被拒绝。
- 只同步本项目已登记聊天的可见消息，并保留原消息编号。原文同步和草稿保存分别确认。插件关闭或离线后，下一次运行可按本机登记补传，网页学习记录显示最近同步时间。自动导出的档案随网站数据更新，个人内容放在「我的笔记」。
- 本机项目文件在 Codex 端按需读取。老师网页能查看已上传的材料和已保存的引用。可读取的文件类型、限额和审阅权限以 `project_files.py` 与工具定义为准。
- 两个教学账号可分别登录浏览器；同一系统用户装的插件在一个站点只保存一份当前连接。换账号重新配对会替换连接，历史项目数据仍可追溯。
- 默认模型与网页配置入口见[运行配置](../proposal_app/配置说明.md)。
