# 开题手记插件安装与使用

学生和老师使用同一个 **Research Coach** 插件。打开课堂使用的开题手记，从该站的「插件」页下载对应系统的安装包。本地演示站完成[插件打包与配置](../proposal_app/README.md#连接-codex)后也可体验。

## 初次安装与连接

1. 安装并登录 Codex。Windows 插件包自带 Python。macOS 用户把 Codex 放进「应用程序」，并安装 Python 3.12 或更新版。
2. 登录教学网站。学生从「跟AI教练开始讨论」进入，老师从「请 Codex 辅助审阅」进入。打开连接向导，下载对应系统的安装包，按钮旁会标示实际版本。
3. 解压整个 ZIP。Windows 双击「安装开题手记.cmd」，macOS 运行「安装开题手记.command」。按回车使用包内默认的网址，或改成学校的教学网址。
4. 保持安装窗口打开。回到原网页点「我已有三位连接码」，核对当前账号与角色，填入新码后点「连接这台电脑」。安装窗口显示完成后再关闭。如果 Codex 已经开着，先退出，再打开。
5. 网页进入选文件夹。点「选择文件夹」，从电脑上选一个已有目录，路径会自动填入。点「打开 Codex」，在 Codex 发送网页预填的消息。已验证通过的文件夹可以复用。

## 平时使用

- **学生**从「当前任务」进入讨论，回网页用「核对阶段成果」确认。F 点「核对并提交老师审阅」，查看固定稿和本稿答辩，再点「提交老师」。
- **老师**从「老师工作台」的「待审阅」打开固定稿。可以手工审阅，也可以用 Codex 起草，回网页点「核对并发布草稿」，确认后发布。
- 每个课题使用独立文件夹。学生讨论和老师审阅建议各选自己的目录。换电脑、目录移走或打不开旧聊天时，先从任务进入 Codex，再展开「如果打不开 Codex 或原来的讨论」，点「更换课题文件夹」或「更换审阅文件夹」。接续旧聊天时，在选文件夹窗口使用「恢复本机讨论」。
- 连接失效或切换教学账号时，在「插件」页点「重新连接」，用安装程序生成新码。一个系统用户下，同一站点只保留一份插件连接。浏览器可以分开登录两个角色。纯网页手工审阅可以继续使用学生原有的插件连接。

## 查看保存结果

草稿看「当前任务」或「研究工作区」，已同步原话看「学习记录」。断网或插件关闭期间，原话可能还未上传。下次插件启动后可补传已登记的聊天。老师要看学生本地的日志或附件时，学生需把文件上传到「材料」。

`127.0.0.1` 只表示当前电脑。另一台电脑试教要使用它能访问的教学站点地址，并从该站下载相应的安装包。[系统怎样工作](开题手记-系统架构简介.md)
