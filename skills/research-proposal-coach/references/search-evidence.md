# 来源与检索诊断

本模块说明检索记录和共读操作；来源判断与 claim 规则见主 Skill「决定何时读写」。

## 检索、查读与记录

学生已给原文链接和章节时，直接打开对应原文，尽量一次定位所列章节；核对后按已有来源 ID 复用，别先遍搜项目索引。链接缺失或打不开时，再根据题名、作者或一批检索式找原文。只读和判断有关的结果与适用范围。查项目资料用项目工具按索引读取。

1. 将当前问题写成检索式，组合日常说法与学科术语，实际检索并打开出版社、作者或可靠机构提供的原文。必要时沿综述寻找原始研究，或按题名、作者寻找可访问版本。
2. 按对象、条件、方法及对当前判断的作用选排。记录为何改词、理解怎样变化；未改词或未改变理解也如实记录。同一研究的转载不能算第二篇独立证据。
3. 用`proposal_log_search`保存实际过程。取得并用于讨论的来源用`proposal_source`登记或更新帮助与局限；零结果搜索不虚构source。只有相应回执成功才说已保存。

采用的材料、检索过程和影响研究判断的结论各存一次。结论用 `proposal_quality_record(kind=claim)`，不要再用 `proposal_save_objects` 重存；学生的预测若值得接续，可另存为预测，分清它与论文结论。没有形成新问法、成果或取舍时，不为一轮检索补造记录。

`project.research.contract.search_save`给出当前输入结构，记录内容放在`payload.content`。规范字段为：

| 字段 | 内容 |
| --- | --- |
| query、channel、searched_at | 实际检索式、渠道和日期 |
| selection_reason、term_change_reason | 选排理由和改词原因；未改说明未改 |
| understanding_change | 对当前理解的影响，或尚无变化 |
| result_count | 非负整数；不知道用null |
| reading_scope | full、abstract、excerpt、not_read之一 |

阅读范围按实际取得内容填写，限制另用文字说明。PDF截断、无文字层或访问受阻时，不能声称读完。字段如有更新以运行中的契约为准。

## C的共读条件

学生须指出至少两篇独立来源各一处实际读到的原文，用自己的话比较支持范围、不能声称的结论和对研究问题的影响。导师可以示范定位、解释术语和读图，随后观察学生处理另一段或另一来源；不能代写学生理解来凑齐条目。

没有适用来源时，保存实际检索范围，请老师协助定位适用材料；未满足至少两篇独立来源的完成条件就保持进行中，不承诺替代证据可豁免。
