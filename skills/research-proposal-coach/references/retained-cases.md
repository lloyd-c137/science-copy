# 教学行为回归案例

这些是回归判据，不是已通过证明。每次验收记录输入、模型/Skill/应用版本、读写轨迹、学生原话及通过/失败/未执行；跨阶段从实际保存记录恢复，不在提示中重新补齐应继承的信息。

| 例 | 阶段活动 | 必须保留的判断 |
| --- | --- | --- |
| 1 已换算数据 | D关键验证 | 制作版路线68mm已实测，不再除二；长度不能证明通过能力 |
| 2 示例与摘要 | C查读、D核算 | AI示例12/15/18均值15，不向学生追实测出处；合成摘要不构成因果证据 |
| 3 新维度与拒绝 | A/B→C/D | 迟到次数为主判据，拒绝天气方向及本人理由跨会话读取；无新证据不复议 |
| 4 理解到迁移 | C→D | 路线/出发时间具体对照；听不懂改讲法，新例观察；保存support并下一活动读取，不能仅reflect |
| 5 简单请求 | 任一活动 | 两句话解释图；找论文实际搜索；无结果不能说已找到证据 |
| 6 暂停恢复 | D | 保存谁联系参与者、何时继续；恢复不重复；本机运行不冒充现场试用 |
| 7 竞争方向 | A/B | 第五轮仍可保留两方向、暂缓；不造偏好、不以轮数强制定题 |
| 8 深入判断 | D必要时C | A=4/5/6，B=3/5/7，均值都5，B范围更大；热情不证明值得一年；深度随表现提高 |
| Q09 混合来源 | C/D/E | 同轮实测材料、AI示例和摘要逐条claim，各有来源与范围；不合并成已证实结论 |
| Q10 辅导接续 | A/C资源查找后 | 只取得受限数据集介绍时，保留获取限制，并给一个不依赖未取得材料的具体动作或必要问题；已有使用场景则继承，不能重复问；不只以“已保存/还需验证”结束。对照：明确只要两句话解释、暂停或已有待做动作，不机械加问或堆任务 |
| A 试聊与转向 | A | 宽泛兴趣先澄清；列 2–3 个实质不同的方向，可都不选。一次试聊后问继续还是换角度，尊重学生主动暂停。收束时另问是否选定；学生已经明确选定时直接交接。本人取舍和理由有原话记录，转向能追溯旧取舍 |
| 两类核对 | A–F | 整阶段未就绪时，仅给确实阻塞后续的一项选择入口；完成整阶段仍取决于实际预检查。最终总结的要点可在网页草稿中核对 |
| 审阅按需读写 | 老师端 | 固定稿初审有完整上下文时复用，否则读一次；同版用保存回执交接，发生冲突才重读 |
| 按需读写 | 任一活动 | 普通追问零项目工具调用，原文仍归档。新观察、有实质进展的草稿和本人取舍当轮完成对应写入 |
| 绑定失败 | 首次进入 | 普通追问不重试。第一次有应保存内容时说明尚未同步，给可复制要点与具体入口 |

六痛点对应主规则：P01=关键主张/来源；P02=主线/本人决定；P03=支持调整；P04=续接/回执；P05=解释预测取舍/网站决定；P06=直接帮助/预算与必要验证边界。七优点对应主动下一步、具体质疑、可理解结构、可选新维度、示范后迁移、能力提升后加深、从真实需求出发。不要用填满对象代替任何一项。
