Research Coach 插件

下载 Windows 版 ↓ 下载 macOS 版 ↓ 正在读取安装包…

先安装并登录 Codex。macOS 版需要 Python 3.12 或更新版本。

  1. ZIP

    安装插件

    解压安装包，打开「安装开题手记」。确认网址后按回车，等窗口显示三位码。

  2. 037

    连接账号

    回课题页。学生点「跟AI教练开始讨论」，老师点「请 Codex 辅助审阅」。

    点「我已有三位连接码」并输码。安装窗口显示完成后再关。

  3. 选文件夹

    点「选择文件夹」。若 Codex 已打开，先退出，再点「打开 Codex」并发送写好的消息。

连接 Codex

换了电脑、切换账号或连接失效时，重新连接。

怎样升级插件？

下载新版，解压后运行「安装开题手记」，再用新三位码重新连接。

重新连接 Codex

运行「安装开题手记」，输入安装窗口显示的新三位码。
